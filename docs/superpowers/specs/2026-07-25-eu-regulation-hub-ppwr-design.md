## 2. 정보 구조 (확장형 허브)
```
랜딩 nav "유럽 규제"  ─▶  /regulations                (허브: 규제 카드 목록)
```

## 4. 허브 페이지 `/regulations` 레이아웃
1. **히어로**: eyebrow "EU REGULATION" + 타이틀 "EU 수출 규제, 미리 대비하세요" + 서브카피
2. **규제 카드 그리드**: 카드당 [규제명 / 한 줄 요약 / 핵심 시행일 뱃지 / "자세히 보기"]
   - PPWR 카드 = 활성(→ `/regulations/ppwr`)
   - 예정 규제 카드 = "준비 중" 비활성(구조 확장성 시연)
3. **CTA 밴드**: "우리 브랜드는 준비됐을까?" → `/diagnose`

4. **타임라인** — 2026.8.12 → 2040 단계별 의무 적용(수직 타임라인 컴포넌트)
